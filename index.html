bitmark-kernel / browser-node Bitmark · BTM · live coin

A Bitmark node and wallet that run in this browser tab — the bitcoin-kernel/browser-node stack pointed at a real coin. The same consensus engine validates Bitmark's chain; the wallet is backed by an ElectrumX server, so it needs no full-block download. Keys are generated locally and never leave the tab.

Honest corners

Bitmark uses multi-algo PoW; the block-identity hash is SHA256d (validated) but PoW difficulty is not re-checked (delegated, as the reference bitmark-kernel does). Wallet balance/UTXOs/broadcast go through a trusted ElectrumX index rather than a from-scratch scan. Bitmark has no SegWit — addresses are legacy P2PKH (b…, base58 version 85).
