bitmark-kernel / browser-node — keys (generate a Bitmark wallet)

Generate a fresh Bitmark (BTM) wallet in your browser. This is the one page that touches private keys — the seed is created locally (crypto.getRandomValues) and never leaves this tab. Take a receiving address to the wallet to check balance and spend. Bitmark has no SegWit, so addresses are legacy P2PKH (base58, prefix b…). home

⚠ Real coin. BTM has real (if small) value — this is not a testnet. The secret below (mnemonic) is your wallet; anyone who sees it controls the funds. It lives only in this tab and vanishes on reload — write it down to keep the wallet.
