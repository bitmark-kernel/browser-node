bitmark-kernel / browser-node — wallet (Bitmark · BTM)

A Bitmark wallet in your browser: load a mnemonic, see your balance, and send BTM — signed locally, balances and broadcast served by an ElectrumX server over the bridge (no full-block download). Legacy P2PKH (no SegWit). Make a wallet on the keys page. home

⚠ Real coin. BTM has real value. Your mnemonic is your wallet; it stays in this tab and vanishes on reload. Balances/broadcast go through a trusted ElectrumX index; signing is local (keys never leave the tab).

1 · Load wallet

2 · Balance

Run the full node first so it has written its validated UTXO set — then "from my node" reads balance from your own node, no trusted index.

3 · Send

Derives m/44'/177'/0'/{0,1}/i (legacy P2PKH), scans your first 20 receiving + change addresses via ElectrumX, selects coins largest-first, signs each input with the LEGACY sighash (the engine's own verifyInput checks the tx before broadcast), and pushes it with blockchain.transaction.broadcast. Proven in test-keys.mjs / test-sign.mjs / test-sign-multi.mjs / test-electrum.mjs.
